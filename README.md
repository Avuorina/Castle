# Castle

Minecraftでスロット台を設置して遊ぶためのデータパックです。

`item_display` / `text_display` / `interaction` などのエンティティを組み合わせて、リール・ボタン・レバー・入金機・ポイント表示を持つスロット台を作ります。

> [!NOTE]
> 現在は開発中です。未実装の役やデバッグ用表示が含まれています。

## 対応環境

- Minecraft Java Edition向けデータパックです。
- `pack.mcmeta` の `pack_format` は `94` です。
- 表示には `custom_model_data` の文字列を使っています。見た目を正しく表示するには、対応するリソースパックが必要になる可能性があります。

## 導入方法

1. このリポジトリをワールドの `datapacks` フォルダに配置します。
2. ワールド内で次のコマンドを実行します。

```mcfunction
/reload
```

3. 読み込みに成功すると、`main:load` によってスコアボード、定数、リール配列などが初期化されます。

## 基本的な使い方

### 設置ツールを入手する

```mcfunction
/function player:tools/give/install
```

このコマンドで、スロット台を設置するための「設置ツール」を入手できます。

### 撤去ツールを入手する

```mcfunction
/function player:tools/give/uninstall
```

このコマンドで、近くのスロット台を撤去するための「撤去ツール」を入手できます。

### スロット台を設置する

1. 設置ツールを持ちます。
2. 設置したい方向を向きます。
3. 設置ツールを使用します。
4. プレイヤーの向きに合わせてスロット台が設置されます。

### スロット台を撤去する

1. 撤去ツールを持ちます。
2. 撤去したいスロット台の近くで使用します。
3. 最寄りのスロット台一式が削除されます。

## ゲームの流れ

1. お金アイテムを入金機に投入します。
2. 右画面の「球貸」を押して、投入金額をメダルに変換します。
3. レバーを引きます。
4. 左・中・右のボタンを押してリールを止めます。
5. 役に応じてメダル払い出しやポイント加算が行われます。

## お金・メダル仕様

このデータパックでは、以下のアイテムをお金として扱います。

| 金額 | アイテム | 主な用途 |
| ---: | --- | --- |
| 100円 | `minecraft:gold_ingot` | 100円玉 |
| 1,000円 | `minecraft:emerald` | 1,000円札 |
| 10,000円 | `minecraft:diamond` | 10,000円札 |

スロットに投入できるのは100円玉以外です。
スロット台に投入された金額は `Invest` スコアで管理されます。

球貸では、現在の実装上 `1,000円 = 46メダル` として変換されます。

## スロットの主な状態

スロット台は `SlotState` スコアで状態を管理しています。
詳細な仕様（ResultIDや図柄IDの一覧）については [`docs/slot_spec.md`](docs/slot_spec.md) を参照してください。

| SlotState | 意味 |
| ---: | --- |
| 0 | 待機中。レバーを引ける状態 |
| 1 | レバーが引かれ、役抽選に入る状態 |
| 2 | 役が決定した状態 |
| 3 | リール回転中 |

## 主な役

通常時の役抽選では、主に以下の役が使われます。

| 役 | 概要 |
| --- | --- |
| カス役 | 払い出しなし |
| リプレイ | リプレイまたは少量払い出し |
| ルーン | 複数パターンに分岐し、ポイント加算や払い出しを行う |
| ベル | 15枚払い出し |
| ニンゲンヤメマスカ | 現在は未実装 |

## デバッグ

`main:load` では `Debug` チームが作成されます。

開発中の確認用として、`Debug` チームのプレイヤーがいる場合にメダル支払いを補助する処理や、アクションバーへのスコア表示があります。

Debugチームに入る例:

```mcfunction
/team join Debug <プレイヤー名>
```

Debugチームから抜ける例:

```mcfunction
/team leave <プレイヤー名>
```

> [!WARNING]
> デバッグ用処理はゲームバランスに影響する可能性があります。通常プレイや配布時は扱いに注意してください。

## ディレクトリ構成

| パス | 役割 |
| --- | --- |
| `data/main/` | ロード・tickの入口、スコアボード・定数初期化 |
| `data/slot/` | スロット台本体、設置・撤去、リール、ボタン、レバー、払い出し |
| `data/money/` | お金アイテム、所持金検知、両替・表示 |
| `data/player/` | プレイヤー操作検知、ツール、ポイント表示 |
| `data/api/` | プレイヤー方向取得、リール位置制御などの内部API |
| `data/indev/` | 開発中・デバッグ用の表示処理 |
| `data/minecraft/tags/function/` | `load` / `tick` タグ |
