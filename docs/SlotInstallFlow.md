# スロット台設置フロー

スロットの設置処理のフローをまとめたよ！

## 1. 実行者チェック (`.mcfunction`)
まず実行者がいるかどうかを確認するよ。実行者がいない場合はエラーメッセージを出して処理を終了するね。

## 2. プレイヤーの向き検知 (`.mcfunction`)
`api:player/direction` を実行して、プレイヤーが向いている方向を判定するよ。これで台の向きが決まるんだ。

## 3. 台本体の設置 (`.mcfunction`)
向いている方向（0, 90, -90, 180）に合わせて座標を微調整して、透明な `armor_stand`（タグ: `slot_machine`, `slot_new`）を召喚するよ。これがスロット台の本体になるよ。

## 4. パーツの召喚と配置 (`place_parts.mcfunction`)
台本体（`slot_new`）の位置を起点にして、周りの装飾やギミックを相対座標（`^ ^ ^`）で召喚していくよ。
*   **ステータスリセット**: `SlotState` を待機中（0）にセットするよ。
*   **リールの設置**: 左右と中央の3レーン分、上中下段の `item_display` と背景のガラスを召喚するよ。
*   **操作系の設置**: ボタン（左・中・右）とレバーの当たり判定（`interaction`）と見た目（`item_display`）を配置するよ。
*   **各種ディスプレイ**: メダル枚数、右画面（球貸）、入金機、ポイント、ステージ表示を順番に召喚するよ。
*   **向きとサイズの調整**: 最後に全パーツの `Rotation` を台本体と同じ向きに揃えるよ。一部のパーツはサイズを半分にして、右画面は少し内側を向くように角度を調整してるんだ。

## 5. 台の初期化 (`init.mcfunction`)
パーツの配置が終わったら、台の初期セットアップを行うよ。
*   **リールのランダム初期化**: リールの位置（`SlotPos_*`）を0〜19のランダムな値に設定して、リールの表示を更新するよ（`slot:reel/update/`）。
*   **各種変数のリセット**: `ButtonState`、`Medal`、`InPayout`、`Invest` を全部0にリセットするよ。
*   **ID割り振り等**: 遅延配置（`custom_lazy/`）、IDの割り振り（`slot:play/set_id`）を実行して、金額表示（`slot:money/update`）を反映させるよ。
*   **仕上げ**: 最後に台と周辺パーツから `slot_new` タグを消して、初期化完了だよ。

## 6. 完了メッセージ (`.mcfunction`)
すべての処理が終わったら、チャットに「スロット台を設置しました。」ってメッセージを出して処理終了だよ！
